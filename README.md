# AgriMarket - B2B Agricultural Marketplace

A modern full-stack B2B marketplace platform connecting South African farmers, agricultural cooperatives, bulk buyers, food processors, and retailers.

## Features
- **Modern Marketplace:** Category browsing (Grains, Fruits, Vegetables, Livestock, Dairy), search, filters, and product details.
- **Administrator Portal:** Seller KYC verification queue, legitimacy scoring, GlobalG.A.P. compliance checks, rejection workflows, and credential management.
- **Database:** Serverless Neon PostgreSQL database integrated with Drizzle ORM.
- **Frontend:** Next.js 16 (App Router), TypeScript, Tailwind CSS, Lucide icons.
- **Backend:** Next.js API Routes and modular backend services.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Neon PostgreSQL
- Drizzle ORM
